# Kelvar LLC — Atmospheric Water Bottle

A responsive, static partner-facing website for the Water-bottle project.

## View locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy
This repository is structured as a static site and can be imported into Vercel with the project root set to the repository root. No framework preset or build command is required; the output is the repository root.

## Website content
- Product concept and intended applications
- Proposed atmospheric water generation architecture
- Preliminary component breakdown
- Safety, water-quality and engineering considerations
- Evidence-based development roadmap
- Partnership invitation

## Important product-status statement
This is a development-stage concept, not a completed or certified consumer product. Water output, energy use, purification performance, operating envelope, manufacturing cost and regulatory compliance must be established through engineering and independent testing. The site intentionally avoids presenting illustrative targets or unverified performance as facts.

## Next technical milestones
